# World Cup Escape ⚽

## About the Game

**World Cup Escape** is a football-themed maze game inspired by the excitement of the FIFA World Cup. The game challenges players to navigate through mazes, avoid obstacles and traps, collect goals, and achieve the highest possible score.

The project was developed using Microsoft Excel VBA, combining programming concepts with an interactive, football-themed gaming experience.

## Features

The game is designed around the following features:

- **Five stages:** Progress through increasingly challenging maze levels.
- **Maze navigation:** Find your way through the maze while avoiding obstacles.
- **Football theme:** Enjoy a football-inspired interface and gameplay.
- **Goals and scoring:** Collect goals and build your score.
- **Lives system:** Avoid hazards to protect your remaining lives.
- **Timer:** Keep track of your gameplay time.
- **High scores:** Track high-score records supported by the current version.
- **Pause and resume:** Control your gameplay using the available game controls.
- **Increasing difficulty:** Face more challenging mazes as you progress.

*Note: Features should be confirmed against the exact version being published.*

## Technologies Used

- Microsoft Excel
- Visual Basic for Applications (VBA)

## How to Play

1. Download the game workbook.
2. Open it using desktop Microsoft Excel.
3. Enable macros only if you trust the workbook and obtained it from the official project page.
4. Start the game using the available game controls.
5. Navigate through the maze, avoid hazards, collect goals, and find the exit.
6. Progress through the stages while trying to achieve a high score.

For more detailed instructions, see `Player_Instructions.md`.

## System Requirements

- A Windows computer with a compatible desktop version of Microsoft Excel.
- The World Cup Escape macro-enabled workbook.
- Permission to run VBA macros, subject to your Excel security settings.

This version runs inside Excel and is not currently a standalone Windows application or a browser-based game.
